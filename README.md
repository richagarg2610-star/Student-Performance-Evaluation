# Student-Performance-Evaluation
Excel-based student performance analysis featuring conditional formatting, formulas, charts, and an interactive-style dashboard.
Student Performance Analysis Using Microsoft Excel

Project Overview
This project analyzes student academic performance across six subjects using Microsoft Excel. It uses formulas, conditional formatting, charts, and a dashboard to turn student records into meaningful insights.

Objectives
Analyze student marks and academic performance.
Calculate total marks, average marks, percentages, and pass/fail results.
Compare performance across six subjects.
Visualize student distribution by city.
Present key findings through a dashboard.

Tools and Excel Skills
Microsoft Excel
SUM, AVERAGE, IF, and COUNTIF formulas
Conditional formatting
Sorting and filtering
Data visualization using charts
Dashboard creation

Key Features
Student records and subject-wise marks
Automatic calculation of totals and percentages
Color-coded marks and results
Subject-wise pass/fail analysis
City-wise student distribution
Dashboard with summary metrics and charts

Key Findings
Analyzed 100 student records.
91 students passed and 9 students failed.
Hindi had the highest average marks among the six subjects.
The dashboard highlights differences in subject performance and areas that may need improvement.

What I Learned
This project helped me practice Excel formulas, conditional formatting, data organization, chart creation, and dashboard design. It also helped me understand how to communicate data insights clearly.

Project Files
The Excel workbook contains the student records, analysis sheets, charts, and dashboard.

Data Privacy
The dataset used in this project is fictional and created for educational and portfolio demonstration purposes. It does not represent real students or individuals.

Conclusion
This project demonstrates practical Microsoft Excel skills for data analysis, reporting, and visualization.
